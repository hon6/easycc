    出口规则
    —

      访问本机

      未授权
      授权后，环境里的 Agent / 浏览器访问 host.internal:端口 就是你电脑本机的 localhost:端口；电脑上的本地证书（mkcert、钥匙串里自己装的根证书）会自动导入，访问本机的 HTTPS 不报证书错误。不授权时环境完全访问不到本机。
      允许 SSH 控制本机
      环境里 ssh host 直接登录你的电脑、能执行命令（用专用密钥，撤销即作废）。权限很大，只在需要时打开。

      完整浏览器（Firefox 或 Chrome，英文界面），和环境同一个出口 IP、时区、语言；WebRTC、定位已关。

      Remote-SSH 选主机 easycc-
