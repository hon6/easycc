每个 Agent，
一个独立的环境

easyCC 在你的电脑上开出互相隔离的小环境，各有各的网络出口、浏览器、时区和语言。Claude Code、Codex、Gemini CLI 装进去就能用，代码仍然留在你自己的硬盘上。

环境里的流量只有一条路可走

防火墙先把所有出站连接拦下，只留一条经过你的代理的路。防火墙装不上，环境就不启动。

环境里的程序Agent、浏览器、终端，跑在独立的 Ubuntu 里
防火墙TCP 透明转给代理核心，UDP、ICMP、IPv6 全部封掉直连一律拒绝
代理核心接管 DNS，查询也经代理发出，不走本地解析
你的代理socks5 或 http，可以再串一层中转
出口 IP网站看到的地址。时区、语言跟着它走
  • 检查通过才放行启动时外网先关着。出口地区、DNS、时区、浏览器语言等十多项检查都通过，才把外网打开。
  • 出口变了就断网放行后每 5 分钟复查。出口 IP 跳出你允许的范围，外网立刻关上。
  • 没通过也能干活终端、文件、本地服务照常用，只是不能上网。后台会自动重试。

代理库：先测再用

代理一行一条粘贴进来，客户端替你测出它真正的出口。

  • 出口 IP、国家、城市、延迟
  • 机房 IP 还是住宅 IP
  • 哪个环境正在用它
  • 生成手机订阅，手机和环境走同一个出口

每个环境单独设定出口规则

固定一个出口 IP，或者只要求留在同一个国家、州省、城市。直连落地节点不稳时，可以加一层中转。

  • 链式代理：环境到中转，再到落地节点
  • 出口规则不满足时自动断网
  • 每个环境有自己的网卡地址、主机名、字体组合和分辨率

启动过程看得见

启动、停止、构建镜像都进任务队列，每一步写在日志里。防火墙有没有生效、出口是哪个 IP，不用猜。

  • 多个环境可以一起启动、停止
  • 失败时日志里有原因

不用的时候不占你的电脑

环境忙起来自动多给 CPU 和内存，闲下来收回。长时间没人用就休眠，内存全部还给电脑，数据都在。

  • 最多加到设置值的 2 倍
  • 默认闲置 30 分钟休眠，可以改
  • 点启动就唤醒
  • SSH 或 VS Code 一连也自动唤醒

从安装到开始写代码

不用懂 Docker，也不用自己配防火墙。

  1. 安装客户端Mac 和 Windows 自带运行环境。Linux 用系统里的 Docker 或 Podman。
  2. 添加代理在代理库里粘贴 socks5 或 http 代理，点检测，看出口和延迟。
  3. 新建环境选代理和项目目录。第一次要在本机构建环境镜像，大约 5 到 10 分钟。
  4. 装上 Agent环境后台里点安装，然后用终端、VS Code 或手机接着干活。

环境管理

客户端首页是环境列表。开发环境挂载项目目录，能跑 Agent 和终端；浏览器环境只有一个独立浏览器，不需要项目目录。

有什么

  • 分组、备注、搜索，按名称、IP、项目都能搜
  • 勾选多个环境一起启动、停止、删除
  • 耗时操作进「任务」页，实时看日志
  • 机器身份（网卡、主机名、字体、分辨率、核数）每个环境不同，需要时可以换一组

怎么做

  1. 点侧栏「环境管理」右边的加号
  2. 填名称，选代理，选项目目录
  3. 「网络」「浏览器」「硬件」页里改出口规则、浏览器、CPU 和内存
  4. 点「创建」，联网检查通过后状态变成「运行中」

代理与出口

环境里的流量只能经你给的代理出去。easyCC 不提供代理，用你自己的。

有什么

  • socks5 和 http 代理，支持账号密码
  • 链式代理：经中转再到落地节点，域名在落地节点解析
  • 在线换代理：先测试再应用，新代理不通自动恢复原来的
  • 出口规则：固定 IP，或限定同一国家、州省、城市
  • 手机订阅：生成 Clash 订阅二维码

怎么做

  1. 侧栏「代理库」右边的加号，一行一条粘贴，例如 socks5://user:pass@1.2.3.4:1080
  2. 点「全部检测」
  3. 新建或编辑环境时从代理库里选

长期使用建议选住宅 IP，机房 IP 更容易被网站限制。

联网检查

环境启动时外网是关着的，检查全部通过才打开。

查什么

  • 防火墙已生效，直连确实被拒绝
  • 代理能连上，透明转发和代理是同一个出口
  • IPv6 已封锁，DNS 由代理接管
  • 出口地区符合出口规则
  • 系统时区、浏览器时区和语言与出口一致

没通过怎么办

  1. 打开环境后台的「网络与代理」，看哪一项没过
  2. 换代理，或点「以当前出口为准」重新记录出口
  3. 后台会自动重试，通过后外网自己打开

AI Agent

环境默认不预装 Agent，用哪个装哪个。

有什么

  • Claude Code、Codex、Gemini CLI、Cursor CLI、Copilot CLI、opencode、Qwen Code、Kimi CLI
  • Agent 跑在 tmux 里，关掉终端也不会停
  • Agent 知道自己在什么环境里：资源多少、项目在电脑上的位置、外网是否开着

怎么做

  1. 启动环境，打开环境后台的「Agent」页
  2. 点要用的那个「安装」
  3. 回到客户端，点环境行里的终端按钮
  4. 第一次按 Agent 的提示登录，登录状态留在这个环境里

环境浏览器

每个环境自带一个在网页里打开的浏览器桌面。

有什么

  • Firefox 或 Chrome，英文界面，锁定走代理
  • 关掉了 WebRTC、定位和 DoH，不会漏出真实 IP
  • 环境里的 localhost 就是环境自己的：Agent 起的开发服务器，在这里直接打开

把链接送进去

  1. 客户端里点环境行的链接按钮
  2. 或者把「设置」里的「发送到 easyCC」拖到电脑浏览器的书签栏
  3. 或者命令行：easycc open us1 链接

在环境里写代码

代码在你的电脑上，环境负责跑 Agent。

有什么

  • 环境挂载一个项目根目录，其下的项目随时切换
  • 每个环境都有 SSH，主机名是 easycc-环境名
  • 可以把环境里的端口转到电脑的 localhost
  • 可以授权环境用 ssh host 回到电脑上跑重活

怎么做

  1. 点环境行里的 <> 按钮，VS Code 或 Cursor 自动用 Remote-SSH 打开项目
  2. 或者在任何终端里 ssh easycc-us1
  3. 换项目：环境后台的「项目目录」页

电脑上要装好 VS Code 或 Cursor，以及 Remote-SSH 扩展。

手机远程

出门在外也能盯着 Agent 干活。

有什么

  • 环境里自带 Kiteline，后台显示配对二维码和 6 位验证码
  • 手机经中继连进来，同样走这个环境的出口
  • 能看到 Agent 的实时输出，继续下指令、确认操作

怎么做

  1. 打开环境后台的「手机 · Kiteline」页
  2. 手机上打开 Kiteline，扫二维码或输入验证码
  3. 配对后就能在手机上看到环境里的会话

Kiteline 目前只有 x86_64 版本。Apple 芯片的 Mac 上，带 Kiteline 的环境经 Rosetta 运行。

资源与休眠

环境用多少拿多少。

有什么

  • 自动伸缩：CPU 持续跑满、内存快满时自动加，最多到设置值的 2 倍，闲下来收回
  • 空闲休眠：没有连接、没有 Agent 在跑、CPU 也闲着，超过设定时间就停下环境
  • 自动唤醒：启动、打开链接、SSH 或 VS Code 连接时唤醒

在哪设置

  1. 「设置」页的「资源」：开关自动伸缩，选闲置多久休眠
  2. 编辑环境的「网络」页：打开「一直运行，不自动休眠」

自动伸缩支持 Docker、Podman 和 easyCC 自带的虚拟机。Apple container 不能在运行中调整，只做休眠。

导出、导入与复制

环境不绑死在一台电脑上。

有什么

  • 导出成一个文件，包含代理和设置，可选带上浏览器和 Agent 的登录状态
  • 复制出一个设置相同的新环境，登录数据不复制
  • 环境数据可以挪到别的硬盘

怎么做

  1. 环境行最右边的菜单里选「导出环境」
  2. 新电脑上在「环境管理」页导入

带登录状态的导出文件能直接登录你的账号，请像密码一样保管。

环境后台

每个环境自己的控制台，从客户端的环境行里打开。只监听本机，别人访问不到。

各页做什么

  • 总览：流量路径、出口 IP、检查评分
  • Agent：安装、切换默认 Agent
  • 网络与代理：每项检查的结果，在线换代理，暂停或恢复外网
  • 项目目录：浏览并切换当前项目
  • 手机 · Kiteline：配对二维码和验证码
  • 维护：一键重置环境，项目文件不动

打开方式

  1. 开发环境：点环境行里的后台按钮
  2. 浏览器环境：环境行菜单里的「环境后台」
  3. 命令行：easycc admin us1

命令行

客户端和 easycc 命令用同一份数据，可以混着用。

easycc ui
打开客户端
easycc create us1 --dir ~/code/myapp --proxy 'socks5://user:pass@1.2.3.4:1080'
新建环境
easycc start us1
启动。停止和重启是 stop、restart
easycc list
列出所有环境
easycc claude us1
在环境里运行 Claude Code
easycc code us1
用 VS Code 或 Cursor 打开环境
easycc admin us1
打开环境后台
easycc open us1 https://example.com
在环境浏览器里打开链接
easycc project us1
切换项目目录
easycc ports us1
查看和添加端口转发
easycc status us1
出口 IP、时区和封锁情况
easycc wake us1
唤醒休眠中的环境，SSH 连接时会自动调用
easycc build --arch amd64
重新构建环境镜像。arm64 是原生版，不带 Kiteline
easycc rm us1 --purge
删除环境和它的数据，项目目录不动

常见问题

easyCC 收费吗？

不收费，代码开源。安装和使用都不需要注册账号。

代理要自己准备吗？

要。easyCC 不提供代理，你在代理库里填自己的 socks5 或 http 代理。

我的代码会被上传吗？

不会。项目目录是从你的电脑挂进环境的，代码一直在你自己的硬盘上，环境数据也都存在本机。

环境占多少电脑资源？

每个环境默认上限是 4 核、4G 内存，可以改。实际占用按用量来。闲置超过设定时间会自动休眠，内存全部还给电脑。

联网检查没通过怎么办？

打开环境后台的「网络与代理」页，看哪一项没过。常见原因是代理不通、出口地区不在支持范围，或者出口 IP 和上次不一样。换代理，或点「以当前出口为准」，后台会自动重试。

Apple 芯片的 Mac 能用吗？

能。默认的环境镜像是 amd64，带 Kiteline，经 Rosetta 运行。也可以构建 arm64 原生镜像，更快，但没有 Kiteline。

easyCC 会收集哪些数据？

客户端默认每 10 分钟发一次匿名使用统计：一个随机设备号、系统版本、CPU 和内存大小、客户端版本、环境数量和用量、出口国家、装了哪些 Agent。不发环境名、备注、项目、代理地址、出口 IP 和任何登录数据，服务器也不记录你的 IP。在「设置」页的「隐私」里可以关掉。
